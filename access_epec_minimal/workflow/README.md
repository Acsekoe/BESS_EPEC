# workflow/

Handoff notes and session summaries.

Write one Markdown file per working session, named
`summary_YYYY-MM-DD_HH-mm.md`, containing:

- current objective,
- decisions made and why,
- files changed,
- verification actually run, with numbers,
- next steps.

Keep them concise and actionable. Record what was *verified*, and state
plainly what was not.
