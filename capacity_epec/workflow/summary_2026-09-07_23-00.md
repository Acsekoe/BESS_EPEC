## The core finding

**The problem.** Every run failed its audit with the same ~68,000 EUR/day
profitable deviation for I3, across every market design and every stabilizer
setting. It was assumed to be numerical. It was not.

**The cause.** I3's best response sits on a price discontinuity. At midday,
renewables exceed demand, storage absorbs the surplus, and the LMP is pinned at
~17 EUR/MWh — which is what I3's own PV is paid. I3 can flip that regime by
building ~20% more storage, jumping the midday LMP to ~39 and its generation
rent from 134,715 to 207,355 EUR/day. Net **+67,680** — the missing 68k. Its
storage operating surplus goes to *zero* in the process: the capacity earns
nothing as storage, it is a price-support instrument. Control: I1, owning no
generation, only loses from the same overbuild.

The discontinuity was an artifact of price formation — demand effectively
perfectly inelastic (0.12 MW response per node at 60 EUR/MWh) and only three
thermal steps, leaving nothing offered between ~17 and 52.2 EUR/MWh.

**The fix** (`market_data_smoothed.json`): a nine-step thermal ladder spanning
23–68 EUR/MWh with total capacity preserved at 820 MW, plus demand-adjustment
penalty 500 → 25.

| | unsmoothed | smoothed |
|---|---|---|
| withholding gradient at 0.1% | +67,906 EUR/day | +469 | 
| I3 audit gap | 68,005 | 14,684 (sweep 80) |
| embedded-vs-reclear gap | 118.66 | 0.36 |
| sub-solve terminations | mixed `maxIterations` | all `optimal` |
| investor spread | 0.94 MW | 22.9 MW and growing |

The −99% embedded-vs-reclear result matters independently: it removes the dual
degeneracy that `access-epec-branch-structure` recorded as inflating MPEC
profits up to +65% in RES-surplus hours.

## Open problem: branch switching

Nothing has converged. `iteration_converged: false` in every run. The obstacle
is now well characterised:

Inside a branch the damped Jacobi map contracts cleanly — the 0.5 run reached a
residual of **0.564** against a 0.5 MW tolerance. Then a branch jump blows it
back to 10–39 MW. It is not slow convergence, it is repeated regime changes.

This is exactly what `access-epec-branch-structure` concluded for the earlier
model: *failure comes from branch switching, so step-size tuning is not the
remedy — branch-aware (multistart + validated) best responses are.*

Note the awkwardness: **multistart is the documented remedy and it is currently
off.** It was switched off for good reason — it was preventing convergence
*within* a branch by perturbing every 5th sweep. The sensible compromise is low
damping to converge inside a branch, then multistart **once at the end** to test
whether the branch reached actually dominates.

## Do not retry

- **Damping 0.5** (`output/smoothed_continued_d05_from_sweep80/`, kept as
  evidence). Oscillates between branches for all 80 sweeps; spikes of 30.4, 34.6,
  39.2 MW; total capacity drifts 188 → 217 MW; nodal configuration wanders
  N6/N8 → N3/N9 → N1/N4. The rationale that motivated it — "damping only changes
  speed of approach, not the best response" — is **wrong** when the
  best-response correspondence is discontinuous: larger steps land in different
  basins, so damping directly controls branch-crossing frequency.
- **Per-node quadratic investment cost as a de-concentration tool.** Implemented
  and tested at qP=qE=50; moved *zero* capacity to the low-value nodes. The
  four-node concentration is real economics — measured LMP spread is 45–49
  EUR/MWh at N3/N6/N8/N9 vs 7.8 at the others. Report it as a finding, not a
  defect.
- **Portfolio-total quadratic cost** (the pre-existing
  `--quadratic-cost-power-eur-per-mw2`). Its gradient is identical at every node,
  so it cannot break a siting tie by construction — it only taxes aggregate size.

## Decided but not implemented

- **Strategic RES withholding**: assessed and deliberately not adopted. The model
  already contains the same market power via the storage channel; the lever was
  a knife edge; it would produce one dominant player rather than a split.
  Revisit only on smoothed price formation. Design sketch is in the session
  report if wanted.
- **Wind market power**: possible but must be designed in — 315 MW relocated to
  N6 (behind the tight L46/L69 corridor) gives a smooth monotone incentive worth
  up to +56,064 EUR/day. Deliberately not in the smoothed input; belongs in its
  own scenario file, and any write-up must state it was designed rather than
  discovered.

## Verification guidance

- Judge convergence from **raw best-response residuals**, not damped state
  changes, and not from investor totals — the sweep-18 branch jump in the 0.5 run
  was completely invisible in the totals and only showed up per node.
- Validate every profit claim with an exact reclear beside the MPEC number. These
  now agree to ~0.001%; if that gap grows again, suspect price formation first.
- Before concluding a persistent audit gap is numerical, probe it directly: fix
  capacities, perturb one investor, reclear, settle. Three sessions of stabilizer
  tuning would have been saved by one such probe.
- `run_config.json` now records `initial_capacities` (path + sha256) and
  `start_is_symmetric`. Warm-started runs previously claimed a symmetric start
  they never had — check this field before comparing runs.
