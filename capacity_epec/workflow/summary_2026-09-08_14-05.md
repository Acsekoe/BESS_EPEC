# Capacity EPEC — reproducible equilibrium-search plan

Last updated: 2026-09-08, 14:05 Europe/Vienna.

This note defines the plan for turning the exploratory equilibrium search into
one reproducible, portfolio-independent algorithm. It supersedes the idea of
reporting a long damped-Jacobi trajectory as the equilibrium method. The
existing manual scans and Jacobi unordered/ordered experiments remain useful
diagnostics, but the final reported equilibrium must be regenerated from the
declared 5 MW / 15 MWh symmetric start without manual intervention.

---

## 1. Motivation from the completed experiments

The experiments have established that distance between capacity vectors is not
a sufficient equilibrium criterion in this model:

- small power/energy movements can cross a price-support boundary and be worth
  thousands of EUR/day;
- large nodal or energy reallocations can lie on an almost flat profit plateau;
- simultaneous Jacobi updates can transfer regret between investors and jump
  between branches;
- sequential Gauss–Seidel updates can produce a low-regret endpoint, but the
  endpoint depends on which investor moves last.

The 10-sweep undamped tests from the same sweep-254 profile illustrate this:

| Profile | I1 regret | I2 regret | I3 regret | Maximum regret |
|---|---:|---:|---:|---:|
| Common starting profile | ~0.01 | ~370 | ~5,539 | **~5,539 EUR/day** |
| After undamped Jacobi | ~5.99 | ~115 | ~16,532 | **~16,532 EUR/day** |
| After undamped Gauss–Seidel, order I1→I2→I3 | 0 | ~989 | ~2.27 | **~989 EUR/day** |

The Gauss–Seidel endpoint is the best audited candidate found so far, but it is
not an equilibrium. I3 moves last and is nearly satisfied, while I2 retains the
material profitable deviation. It is a development benchmark for the new
method, not the final reported result.

## 2. Formal equilibrium criterion

For capacity profile `x`, define investor `i`'s exact-recleared regret as

```text
r_i(x) = max over feasible deviations xhat_i of
         profit_i(xhat_i, x_-i) - profit_i(x).
```

The common merit function is

```text
R(x) = max_i r_i(x).
```

The profile is an epsilon-equilibrium when `R(x) <= epsilon`. For the later
shared-node-capacity GNEP, the deviating investor's feasible set is conditional
on the rivals' fixed capacity and the remaining nodal headroom.

### Proposed target

Use **epsilon = 20 EUR/day** as the primary stopping target, subject to final
calibration before the clean runs. This is a demanding but potentially
defensible value because it is:

- about 0.02–0.03% of the active portfolio owners' daily profits;
- roughly an order of magnitude above the recent embedded-versus-exact-reclear
  discrepancies;
- directly interpretable in the monetary units of the game.

Do not report only a Boolean convergence flag. Always report the achieved
maximum absolute regret and each investor's relative regret. Also show how the
conclusion changes at epsilon values of 10, 20, 50 and 100 EUR/day. Near-zero
profits make percentage-only criteria unreliable, so the formal epsilon remains
a common absolute monetary tolerance.

Acceptance additionally requires:

1. exact-recleared regret at or below the declared epsilon;
2. embedded-versus-reclear error below a separately declared numerical limit,
   initially 2 EUR/day;
3. valid primal feasibility, bounds and complementarity diagnostics;
4. at least two independent deterministic multistart audits;
5. robustness to a tighter complementarity treatment before the final claim.

## 3. Proposed algorithm: regret-guided, branch-aware diagonalisation

The algorithm starts directly from the symmetric initial profile:

```text
X_power[i,n]  = 5 MW
X_energy[i,n] = 15 MWh
```

It does not first run a hard-coded number of Jacobi sweeps, and it never
hard-codes I3 or the PV nodes as the problematic portfolio.

### Outer iteration

At iteration `k`:

1. Freeze the complete current profile `x_k`.
2. Exact-reclear the incumbent market and calculate every current profit.
3. Calculate deterministic multistart best-response candidates for every
   investor, exact-reclear every retained response, and calculate all regrets.
4. If all final-quality regrets satisfy epsilon, perform an independent audit
   and stop.
5. Otherwise select the investor with the largest normalized regret.
6. Form that investor's best-response direction

   ```text
   d_i = BR_i(x_k,-i) - x_k,i.
   ```

7. Search piecewise along

   ```text
   x_i(alpha) = x_k,i + alpha * d_i,   0 <= alpha <= 1.
   ```

8. Select the feasible trial profile that minimizes the validated or screened
   maximum regret `R(x)`.
9. Accept a trial only if it produces a declared sufficient reduction in
   maximum regret; otherwise escalate to a joint search along the two
   largest-regret response directions.
10. Checkpoint the accepted profile and repeat.

Standard update rules are special cases of this framework:

- undamped Jacobi applies `alpha = 1` to every player simultaneously;
- damped Jacobi applies one predetermined common `alpha`;
- Gauss–Seidel applies `alpha = 1` sequentially;
- damped Gauss–Seidel applies predetermined sequential step sizes;
- the proposed method selects the player, branch and step from economic regret.

### Joint fallback

If no one-investor direction lowers maximum regret, take the two investors with
the largest regrets and search a small deterministic grid:

```text
x(alpha_i, alpha_j)
  = x_k + alpha_i * d_i + alpha_j * d_j.
```

The shared nodal limits must be enforced when constructing every trial. This
two-direction search is the systematic version of balancing I2's and I3's
conditional deviations; it must not depend on which investor happens to update
last.

---

## 4. Piecewise branches and plateau tie-breaking

One IPOPT solution is not treated as the unique best response. Multistart may
find a set of economically equivalent or near-equivalent responses:

```text
B_i(x) = candidate responses whose exact profit is within delta of
         the best exact-recleared response found for investor i.
```

Retain these branches and test their update directions separately. Use a
predeclared profit tie tolerance `delta`. Among candidates with indistinguishable
validated regret, apply deterministic tie-breaking in this order:

1. lowest maximum regret;
2. lowest sum of regrets;
3. smallest capacity distance from the incumbent;
4. fixed candidate-label ordering.

This prevents IPOPT warm starts or arbitrary player order from defining the
economic outcome on a flat response plateau.

---

## 5. Computational strategy

A full multistart MPEC audit at every trial point would be unnecessarily
expensive. Use two levels:

### Cheap screening

- reuse the best-response candidates from the frozen base profile;
- exact-reclear those candidate deviations against each trial profile;
- scan a deterministic step grid, initially `alpha = 0.0, 0.1, ..., 1.0`;
- retain the best two or three trial profiles.

### Full validation

- recompute all investors' multistart best responses at each finalist;
- exact-reclear the incumbent and every proposed deviation;
- select the finalist with the lowest validated maximum regret;
- refine the alpha grid locally if useful.

The cheap screen guides the search but never certifies equilibrium. Only the
fresh multistart audit at the frozen finalist can do that.

## 6. Reproducibility requirements

Every accepted outer iteration must record:

- full nodal power and energy profile;
- exact current profits;
- all screened and refined best-response candidates;
- exact-recleared candidate profits;
- absolute and relative regrets;
- candidate branches and start labels;
- all tested step sizes and trial merit values;
- selected step and deterministic selection reason;
- solver termination, feasibility, complementarity and primal-dual diagnostics;
- embedded-versus-reclear errors;
- data, starting-profile and code hashes;
- solver version, configuration and deterministic random seed;
- cumulative runtime and solve counts.

The final experiment must run from the symmetric 5 MW / 15 MWh profile using
one command and no hand-edited intermediate capacity files. The current
hand-generated profiles remain regression targets: the automated method should
reach a result at least as good as the ~989 EUR/day Gauss–Seidel candidate and
then continue toward the 20 EUR/day target.

## 7. Limitations and anticipated reviewer objections

### Local rather than globally certified best responses

IPOPT supplies local NLP solutions. Structured multistart improves the search
but is not a mathematical global-optimality certificate. The appropriate claim
is therefore **numerically validated epsilon-equilibrium under the documented
multistart search**, not globally certified equilibrium.

### No general convergence guarantee

The regret function is non-smooth and may be discontinuous or set-valued across
market branches. Accepting only regret-reducing steps makes the recorded merit
sequence monotone, but it does not prove convergence to zero. The method must
report stagnation or failure honestly if it cannot reach the target.

### Restricted search directions

A line between an incumbent and one best response is only a one-dimensional
slice of the full strategy space. Multiple retained branches, periodic complete
best-response regeneration, nodal relocation starts and the two-direction
fallback mitigate this limitation. The unrestricted final audit is mandatory.

### Path dependence and tie-breaking

Initialization, player ordering and solver starts can affect non-convex games.
The primary result uses the declared symmetric start and deterministic rules;
robustness runs use alternative starts and reversed orders. Different
low-regret endpoints should be reported as equilibrium multiplicity rather than
silently selecting one.

### Computational cost and scalability

The method nests exact market reclears and MPEC best responses inside a
piecewise outer search. Runtime will grow with investors, nodes, branches and
trial points. Report solve counts and runtime and compare them against standard
Jacobi and Gauss–Seidel, not only against sweep count.

### Solver rather than behavioural interpretation

The method assumes centralized access to every payoff and best-response model.
It is a computational equilibrium-recovery algorithm, not a claim about how
real investors learn or update their capacity choices.

### Numerical and market-formulation sensitivity

Any final result remains conditional on the smoothed thermal ladder, elastic
demand term, price/dual bounds and MPCC relaxation. The final candidate must be
checked using tighter complementarity settings, strong duality where practical,
bound sensitivities and repeated exact reclearing.

### Later GNEP extension

With binding shared nodal limits, each player's feasible response depends on
rival capacity. Trial construction and multistart profiles must use remaining
nodal headroom. The intended generalized-Nash solution concept—ordinary GNE
versus a variational equilibrium with a common scarcity price—must be stated
before interpreting scarce-capacity allocations.

## 8. Methodological contribution and evidence required

The potential contribution is not merely “Gauss–Jacobi with different
damping.” It is a **regret-guided, branch-aware diagonalisation method with
adaptive piecewise step selection and exact-reclear certification**.

To support that contribution:

1. formalize the algorithm in pseudocode and freeze its thresholds;
2. implement it without investor-specific logic;
3. regenerate the result from the symmetric 5/15 start with one command;
4. benchmark against damped Jacobi, undamped Jacobi and Gauss–Seidel;
5. report regret paths, runtime, MPEC solves and market reclears;
6. ablate adaptive player selection, line search and multi-branch retention;
7. test at least one different investor ownership portfolio;
8. validate the final candidate independently;
9. later apply the same method to a binding shared-node-capacity GNEP.

The method may be a substantial thesis-level methodological contribution even
without a universal convergence proof. A broader novelty claim requires a
literature comparison with existing best-response, merit-function,
Nikaido–Isoda, line-search and equilibrium-relaxation methods.
