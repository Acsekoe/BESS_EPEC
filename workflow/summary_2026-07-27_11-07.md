# Auction-MPEC handoff — 2026-07-27 11:07

## Current objective

Test an isolated two-investor nodal-access auction at N8 before extending it to
the full investor set or additional nodes. Each investor is a strategic leader;
the access auction and fixed-demand electricity spot market are the two
followers. Gauss--Seidel will approximate the multi-leader/two-follower EPEC by
solving investor best responses sequentially.

All auction-specific formulation, case data, outputs, and documentation remain
under `model/auction/` so the experiment can be removed without changing the
maintained spot-only EPEC.

## Important decisions

- Only N8 is economically active in the current diagnostic. N1--N7 and N9 are
  still instantiated but both investors have zero bids there, and the active
  investor is prevented from opening them.
- The experimental settlement rule is uniform price:
  `access_payment[i,n] = auction_capacity_dual[n] * award[i,n]`.
- The price-selection convention is the **minimum supporting capacity dual**.
  The independent dual reclear is restricted to the optimal auction-value face
  node by node and then minimizes the capacity dual. This selects the right-hand
  shadow value at a degenerate capacity breakpoint.
- Allocation ties use a deterministic merit offset (`--tie-break-epsilon`). It
  is a small perturbation of the merit order, not a claim that the unperturbed
  auction is unique.
- A profit-maximizing uniform-price response can have a continuum of winning
  bids because the investor does not pay its own bid. The optional
  `--refine-minimum-bid` rule therefore performs a second solve: retain primary
  profit within tolerance, retain the primary access price, require a small
  submitted-price margin above any rival left unfilled by the primary response,
  and minimize the submitted bid. This is a lexicographic best-response
  refinement, not an artificial bid cost.
- The Gauss--Seidel driver rejects a positive-award uniform-price response if
  its embedded price differs from the independently selected minimum-supporting
  price by more than `--access-price-reclear-tol` (default 0.001 EUR/MW/day).
- The explicit zero-bid outside-option comparison remains enabled by default.

## Acceptance checks for `I1_minimum_bid.json`

Check all of the following before running the strategic loop:

1. **Both stages solved**
   - `termination == "optimal"`;
   - `minimum_bid_refinement_requested == true`;
   - `minimum_bid_refinement_termination == "optimal"`.
   - Do not rely on `termination` alone: if refinement fails, the code restores
     the primary solution and can still report the primary termination.

2. **Profit was preserved**
   - `profit_eur_per_day >= primary_profit_eur_per_day - 0.01`;
   - spot revenue, CAPEX, degradation, and access payment remain economically
     consistent with the primary solution.

3. **The refined bid has the intended interpretation**
   - I2 remains fixed at 30 EUR/MW/day;
   - I1's N8 bid should be near 30.001 EUR/MW/day, subject to solver tolerance;
   - a materially higher bid means the secondary solve did not reach the
     minimum-bid branch;
   - a bid below the stated rival-plus-margin rule indicates a formulation or
     feasibility-tolerance problem.

4. **Allocation is reproducible**
   - I1 should receive about 100 MW and I2 about zero if the same primary branch
     is retained;
   - `max_embedded_vs_reclear_award_difference_mw` should be numerically small
     (target below `1e-4` MW; investigate anything above `1e-3` MW);
   - N1--N7 and N9 bids and awards should be zero apart from numerical noise.

5. **The price convention is reproduced**
   - `independent_auction_dual_termination == "optimal"`;
   - embedded N8 access price should be about 30.001 EUR/MW/day;
   - `independent_minimum_supporting_access_price_eur_per_mw_day["N8"]`
     should match it;
   - `max_embedded_vs_reclear_access_price_difference_eur_per_mw_day` must be
     at most 0.001 for use in Gauss--Seidel. Prefer a much smaller residual.

6. **Payments reconcile**
   - `access_payment_eur_per_day` should equal embedded N8 access price times
     I1's N8 award, within numerical tolerance;
   - it must not equal I1's submitted bid times its award under `uniform_dual`.

7. **MPEC numerical validity**
   - auction strong-duality gap should be close to zero (target below `1e-5`);
   - spot strong-duality gap should be close to zero (target below `1e-4`);
   - `max_lmp_fraction_of_numerical_bound` should be comfortably below one;
   - storage duration must remain within I1's permitted duration envelope.

## If the refined response fails

- **Primary optimal, refinement not optimal:** first increase CPU time. If it
  persists, inspect the profit floor, access-price ceiling, and rival-margin
  constraints; do not loosen the profit tolerance until the cause is known.
- **Bid remains near 49.98:** the minimum-bid secondary objective is stuck on
  the primary local branch. Try a warm start close to 30.001 or reformulate the
  refinement, rather than interpreting 49.98 economically.
- **Award reclear mismatch:** the embedded allocation is still exploiting a
  tie/optimistic allocation. Stop before Gauss--Seidel and revisit the allocation
  tie rule.
- **Access-price reclear mismatch:** the embedded price does not implement the
  stated minimum-supporting-dual convention. Stop before Gauss--Seidel. A fully
  nested/lexicographic price-selection follower or an explicit highest-rejected-
  bid rule may then be necessary.
- **Profit drops by more than 0.01 EUR/day:** the secondary solve is not merely
  selecting among equivalent responses; reject it as a best-response
  refinement.

## Further work if one sweep is credible

1. Run several two-investor N8 sweeps, initially with damping below one (for
   example 0.5), and test whether quantities, bids, durations, awards, prices,
   and profits converge.
2. Reverse the update order (`I2 I1`) and vary starting bids. A candidate that
   depends materially on order or initialization is not a robust equilibrium.
3. Check for bid leapfrogging, cycling, or repeated marginal overbidding. A
   uniform-price game with continuous bids need not have a unique pure-strategy
   equilibrium; the minimum-bid rule is an explicit equilibrium-selection
   convention and must be disclosed.
4. Only after stable two-investor N8 behavior, open one additional contested
   node. Do not open all nine nodes at once because it obscures whether failures
   come from price selection, siting substitution, or strategic cycling.
5. Add I3/I4 only after the two-investor mechanism is stable and after testing
   whether portfolio generation rents change bidding incentives as intended.
6. Before thesis use, state the complete auction institution: quantity bids,
   bid-price bounds/ticks, merit priority, capacity limit, uniform-price rule,
   minimum-supporting-dual convention, outside option, and equilibrium-selection
   procedure.

## Core caveat

The refined mechanism is more deterministic and defensible than allowing the
leader or solver to return arbitrary profit-equivalent bids and duals. It is
still a local optimistic MPEC plus an explicit selection convention. Successful
diagnostics would establish a coherent computational mechanism for the tested
case, not prove existence or uniqueness of a multi-leader equilibrium.
