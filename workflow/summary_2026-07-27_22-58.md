## Current objective

The immediate research question is whether an explicit nodal BESS-access auction can produce a meaningful four-investor EPEC at N8. Each investor submits a price/quantity access bid, the access auction awards at most 100 MW at the node, and the awarded BESS capacities participate in the nodal spot market.

The auction experiment has now been tested with continuous pay-as-bid prices under both simultaneous Gauss-Jacobi and sequential Gauss-Seidel diagonalization. Several economically motivated starting states were tried. None produced an equilibrium. The experiments expose two structural issues:

1. continuous marginal outbidding has no smallest profitable increment; and
2. the optimistic embedded auction lets each leader select a favorable allocation on an exact or near bid-tie face, even though the common auction cannot award the same 100 MW to every leader.

The next defensible EPEC experiment is exact `0.01` EUR/MW/day tick-grid Gauss-Seidel with deterministic sub-tick tie priority. Continuing the continuous-price runs is unlikely to add information.

## Implemented auction formulation

For each best response, one investor is the upper-level leader. It chooses, at each enabled auction node:

- a bid quantity in MW;
- a raw bid price in EUR/MW/day; and
- a BESS duration/energy choice associated with awarded power.

The leader embeds exactly two lower-level followers using primal feasibility, dual feasibility/stationarity, and strong duality:

1. a nodal access-auction LP; and
2. the fixed-demand nodal spot-market LP.

At a node, the auction is conceptually

```text
maximize    sum_i effective_bid_price_i * award_i
subject to  0 <= award_i <= bid_quantity_i
            sum_i award_i <= node_limit
```

The economic access payment is always raw bid price times awarded MW. The deterministic effective-price offset is used only in optional tick mode to rank equal raw prices; it never enters settlement.

The leader objective contains:

- storage spot revenue;
- any rent on existing generation owned by the investor;
- degradation cost;
- annualized BESS power and energy CAPEX; and
- pay-as-bid access payment.

The clean auction MPEC has no damping, outside-option solve, dispatch regularization, objective penalty, or continuous-price tie perturbation.

## Multi-investor driver behavior

`model/auction/gauss_seidel.py` now supports both update rules:

- `--update-rule jacobi`: all investors solve against the same frozen pre-sweep bid state; all proposals are applied simultaneously; one common auction then clears the complete updated bid vector.
- `--update-rule seidel`: each best response sees and immediately follows the earlier responses in the same numerical sweep; one common auction is still re-cleared after the sweep.

Gauss-Seidel visibility is a diagonalization algorithm for a complete-information simultaneous EPEC. It should not be described as a literal sequential auction unless the investor order is intentionally given economic meaning. A converged fixed point that is robust to update order could still represent a simultaneous EPEC; an order-dependent winner is only an algorithmic artifact.

After the last sweep, the driver performs:

- one independent common auction re-clear;
- one common spot-market clearing with all awarded fleets;
- joint LMP and operation exports; and
- common settled profits for all investors.

The last optimistic best-response profits remain separate diagnostics and are not silently treated as settled profits.

## Critical terminology

### Bid quantity

The bid quantity is the maximum access quantity the investor offers to take. It is not automatically installed capacity. Only the awarded quantity becomes available to the spot follower.

### Embedded award

The embedded award is the active investor's award inside its own MPEC, against the rival bid snapshot used for that individual best response. Different investors' embedded awards belong to different counterfactual auction problems and cannot be added into one feasible allocation.

### Common award

The common award is obtained after the complete updated bid vector is cleared together. It is the physically feasible sweep allocation and the basis for common final settlement.

For a genuine fixed point, an investor's embedded unilateral award must agree with the common allocation. A stable common snapshot is insufficient if losing investors' embedded MPECs still claim that they can receive 100 MW.

## Strengthened convergence test

Convergence now requires all of the following:

- bid-quantity change within tolerance;
- raw-price change within tolerance;
- duration change within tolerance;
- common end-of-sweep award change within tolerance; and
- maximum unilateral embedded-award deviation within tolerance.

The unilateral award condition was essential. Several runs had nearly stationary quantities, prices, and common awards while every losing investor's MPEC continued to claim approximately 100 MW. Such runs are correctly marked nonconverged.

The older zero-start continuous Gauss-Seidel output was created before the strengthened criterion and says `converged=true`. That status is false under the current interpretation and must not be reported as an equilibrium.

## Continuous versus tick bidding

### Continuous mode

Set `--bid-price-tick 0`. Raw bid price is an upper-level continuous variable. There is no merit tie perturbation in the embedded auction.

This mode has a best-response discontinuity: when access allocation changes at a rival cutoff, an investor would like to bid an arbitrarily small amount above that cutoff, but there is no smallest positive increment. At exact or near ties, the optimistic MPEC can select the follower allocation favorable to the active leader.

### Exact tick mode

Set `--bid-price-tick 0.01 --tie-break-epsilon 0.001` at one active node. The driver does not enumerate every cent between zero and the 100 EUR/MW/day cap. For each response it tests only the economically distinct candidates:

- zero;
- each positive rival raw price; and
- one `0.01` tick above each positive rival raw price.

With three positive rivals, this is at most seven MPEC candidates per investor, or at most 28 MPEC solves per four-investor sweep. Equal raw grid prices use the deterministic `0.001` sub-tick investor priority. The maximum four-investor priority spread is `0.003`, which is smaller than one raw price tick and cannot reverse different raw prices.

Each tick candidate is independently checked for:

- optimal solver termination;
- embedded-versus-independent auction award agreement;
- auction and spot strong-duality residuals; and
- pay-as-bid payment reconciliation.

A solver error for one tick candidate is now stored as a failed candidate and does not crash the entire sweep.

## Profit interpretation

Common settlement and optimistic best-response profits differ materially whenever an investor loses the common auction.

For example, in the 100 MW shadow-informed Jacobi final snapshot:

- I1 optimistic profit was about 15,935 EUR/day, but settled profit was about 20 EUR/day;
- I2 optimistic profit was about 15,153 EUR/day, but settled profit was about 0.27 EUR/day;
- I3 optimistic profit was about 136,887 EUR/day, versus settled profit about 124,726 EUR/day;
- I4, the common winner, had optimistic profit about 158,372 EUR/day and settled profit about 155,336 EUR/day.

Portfolio investors I3/I4 can retain large settled existing-generation rents even when they receive almost no BESS access. Therefore, total settled profit should not be mistaken for the incremental value of the awarded BESS.

No nonconverged auction snapshot should be called an equilibrium access price, equilibrium ownership allocation, or equilibrium profit vector.

## Lambda and dual-bound findings

Across all continuous auction experiments, the independently re-cleared spot-market maximum lambda remained approximately 100.684 EUR/MWh. There was no lambda explosion.

Some internal MPEC duals approached the 10,000 bound:

- the zero-start runs reached roughly 96-98% in some responses;
- the 100 MW shadow Jacobi run reached about 99.93%;
- the 100 MW shadow Gauss-Seidel run reached about 99.9995% in the iteration-2 I2 response.

These are not lambda variables. They are internal auction/spot duals and may reflect degeneracy, inactive-node conditions, or optimistic dual-face selection. They remain a serious numerical warning. Optimal solver termination and small strong-duality residuals do not establish economically neutral dual selection.

## Main conclusions established so far

1. **The continuous result depends strongly on the starting price level.** Zero-like starts produce micro-euro bids; the oversubscribed 35.48 seed preserves a price near 35.48.
2. **The physical spot outcome is much less sensitive.** The common auction generally assigns approximately 100 MW at N8, so joint LMPs repeatedly return to the same maximum near 100.684 EUR/MWh.
3. **Starting values do not solve the equilibrium problem.** They change the transient path and price anchor, not the embedded-versus-common allocation inconsistency.
4. **Jacobi does not solve continuous marginal outbidding.** Simultaneous updates rotate the common winner.
5. **Gauss-Seidel does not solve optimistic tie selection.** It can produce an apparently stable common winner while every losing embedded MPEC still claims the full node.
6. **Raw-price uniqueness at `1e-8` scale is not economic uniqueness.** Several summaries report unique raw prices, but their differences are purely numerical.
7. **The headroom multipliers are useful initial-value diagnostics, not clearing prices.** They anchored the oversubscribed experiment but did not define stable pay-as-bid strategies.
8. **A truly private repeated auction is a different model.** If investors observe only their own realized award/profit and do not know rival bids, the appropriate framework is repeated learning or a Bayesian game, not complete-information MPEC diagonalization.
9. **Every auction needs a tie/allocation rule.** Removing all tie rules leaves the follower set-valued. An optimistic MPEC then selects a leader-favorable point on that set.

## Alternative modeling directions if tick EPEC also fails

1. Define an explicit pro-rata allocation rule for exact equal bids. This changes the follower formulation but removes optimistic arbitrary tie selection.
2. Use a repeated auction/learning model in which investors observe only their own award and profit. This answers the user's information-restriction idea but is no longer a complete-information EPEC best-response algorithm.
3. Use a Bayesian sealed-bid model with beliefs about rival bids. This is conceptually appropriate for genuinely private bids but is substantially larger than the current deterministic EPEC.
4. Reconsider the auction payment rule, for example a uniform clearing price or another mechanism with a deliberately specified marginal-price and tie rule. This is a mechanism change, not a numerical fix.
5. Retain the normal projection EPEC as the maintained thesis model and treat the auction branch as a documented failed/diagnostic extension.
