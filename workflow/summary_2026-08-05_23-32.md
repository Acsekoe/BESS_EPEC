# Workflow summary — 2026-08-05 23:32

## Current objective

Test whether reducing IEEE-9 PV availability gives a meaningful but less
extreme BESS investment case, then run the clean capacity-only EPEC without
regularization or penalties. The minimum-norm lexicographic price-selection
experiment is not the intended main formulation because embedding its
secondary ISO KKT system creates an effectively third optimization layer and
does not scale to active rivals.

## Important decisions

- Retain the clean capacity EPEC as the main model: fixed demand, hard nodal and
  system balances, primal/dual feasibility plus exact strong duality, and the
  optimistic dual convention.
- Keep ISO minimum-norm pricing and Tikhonov only as experiments. A `1e-3`
  relaxation of the secondary minimum-norm complementarity condition did not
  resolve the active-rival runtime problem and materially changed one first
  best response.
- Do not eliminate PV curtailment completely if endogenous BESS investment is
  desired. The maximum common PV scale with zero no-storage curtailment is
  approximately `0.72178`; at `0.70` the central planner installs effectively
  zero BESS.
- Use `0.80` PV as the current candidate sensitivity. It reduces the combined
  modeled PV peak from about `671.42 MW` to `537.14 MW`, while retaining
  `96.12 MWh/day` of no-storage curtailment and a moderate congestion-relief
  incentive.
