# Strategic-quantity EPEC handoff — 2026-08-14 13:17 CEST

## Current objective

Build and solve a four-investor Jacobi EPEC in which each investor chooses
nodal BESS MW/MWh capacity and hourly maximum charging/discharging quantities.
The formulation must use a Scholtes-relaxed KKT MPEC, retain SOC constraints in
the upper-level strategy problem, and settle only realized BESS dispatch at the
nodal LMP.

## Modeling decisions

- Hourly quantities are maximum availability offers, not mandatory schedules.
- The ISO/LLP chooses realized charge, discharge, generation, network flows,
  and SOC while minimizing generation cost only.
- The LLP contains no BESS degradation cost.
- Physical degradation remains a private upper-level investor cost based on
  realized throughput.
- Investors receive/pay the LMP only for actual dispatch:
  `sum(lambda * (P_discharge - P_charge))`.
- Investors choose capacity and hourly charging/discharging MW quantities.
- Offered quantities must not exceed installed MW and must be deliverable for
  the complete hour from anticipated beginning-of-hour SOC.
- Realized operation obeys quantity bounds, a shared charge/discharge inverter
  limit, installed MWh, SOC transitions, and cyclic SOC.
- Lower-level optimality is represented by primal feasibility, stationarity,
  dual feasibility, and relaxed complementarity products `0 <= x*y <= epsilon`.
- Strong duality is not used for the strategic-quantity formulation.

## Integration and solver changes

- Added `strategic-quantity` to the maintained Jacobi runner and CLI.
- Quantity profiles are damped alongside MW/MWh capacities and included in
  raw convergence checks.
- Format-v4 checkpoints retain hourly charging/discharging quantity profiles.
- Runs export `final_strategic_quantities.csv`.
- HSL MA57 is the default Ipopt linear solver; MUMPS remains selectable with
  `--ipopt-linear-solver mumps`.
- The installed IDAES Ipopt executable already contains HSL support and solved
  successfully with MA57. The supplied HSL academic-license document does not
  require a separate runtime license file for this binary.
- Strategic-quantity best responses after the first sweep now start from the
  active investor's previous damped capacity and hourly quantities.
- A fixed-bid HiGHS clearing supplies an exact lower-level primal/dual KKT
  initialization. Initial quantities are reduced, only as starting values, to
  the one-hour limits supported by the selected SOC trajectory. The MPEC
  equations, bounds, objective, epsilon, and feasible set are unchanged.
- Ipopt `mu_strategy=adaptive` was tested and rejected because it was much
  slower. `ma57_automatic_scaling` was also rejected because Ipopt 3.13.2 does
  not recognize that option.
- Sparse-capacity cutoffs, cleanup tolerance, complementarity epsilon,
  damping, and convergence tolerances were deliberately not changed because
  doing so would change the mathematical or algorithmic experiment.

## Economic audit of the final damped state

A fresh common HiGHS ISO clearing was performed using the final capacities and
quantity bids.

- Generation cost with final bids: `363,477.11 EUR/day`.
- No-storage generation cost: `394,587.85 EUR/day`.
- System generation-cost saving: about `31,110.74 EUR/day`.
- Generation cost with the same fleet at full availability:
  `363,469.02 EUR/day`.
- Final strategic quantities therefore raise system cost by only about
  `8.09 EUR/day`; they mostly remove unused availability rather than creating
  material system-level withholding.
- Total charge/discharge: `671.10 / 587.95 MWh`.
- No simultaneous charging and discharging was found.
- In hour 19, aggregate discharge availability and realized discharge were
  both about `83.40 MW`; in hour 18 both were about `10.93 MW`. This confirms
  that the intended maximum-quantity mechanism works operationally.
- Diagnostic joint-settlement profits were approximately:
  - I1: `-3,312 EUR/day`;
  - I2: `-3,631 EUR/day`;
  - I3: `130,383 EUR/day`;
  - I4: `214,436 EUR/day`.
- I1/I2 are privately unprofitable because the roughly `52.2` to `60 EUR/MWh`
  arbitrage spread does not cover degradation and daily capex. I3/I4 remain
  profitable because their renewable-generation rents dominate.
- The common LLP has zero BESS operating cost, so dispatch allocation among
  similar units and some dual prices are degenerate. Per-investor common
  settlement is diagnostic and need not match each optimistic MPEC
  best-response profit.
- The final damped offers were not all deliverable from the particular SOC
  trajectories selected by the common reclear: maximum full-offer shortfalls
  were about `4.66`, `5.98`, `0.85`, and effectively `0 MWh` for I1–I4. Actual
  dispatch remained feasible. This is another consequence of stopping before
  the strategy/SOC fixed point.

## Runtime verification

- Comparable MUMPS sweep-4 response times were approximately
  `318.1`, `116.2`, `164.7`, and `267.7 s`.
- An isolated four-worker final-state sweep using MA57 plus the new SOC-feasible
  warm start solved all responses optimally in `112.4`, `172.9`, `53.6`, and
  `58.4 s`.
- Mean response time fell from about `216.7 s` to `99.3 s`; the slowest response
  fell from `318.1 s` to `172.9 s`. Wall time was about `174 s`.
- The isolated benchmark output is retained at
  `model/output/_runtime_smoke_strategic_quantity_sweep6/`. It is a runtime
  test, not a new equilibrium result.
- On I3 alone, MA57 with the former zero-quantity start took `116.0 s`; the new
  warm start took `52.0 s` and reached a higher local objective. Different
  starts may select different local solutions because the MPEC is nonconvex,
  although its mathematics is unchanged.
- Warm-start construction was checked for all four investors: maximum initial
  offer/SOC violation was `5.5e-8 MWh`, the fixed-bid primal-dual gap was below
  `6e-11 EUR/day`, and KKT products were below `4.3e-12`.
